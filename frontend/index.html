    How to use MySQL-Lite 🛠️

    1. Setup: Click the gear icon (⚙️) to enter your MySQL database credentials and a Google Gemini API Key.

    2. Toggle Modes: Use the English or SQL buttons at the top to switch between Natural Language and Typed SQL modes.

    3. Run Queries: Type your query and hit Enter. Need a new line? Use Shift+Enter.

    4. History: Use ↑ and ↓ on your keyboard to navigate through past queries.
